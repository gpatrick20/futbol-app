# Roadmap

## Fase 1 — MVP

- [ ] Configurar estructura inicial del monorepo
- [ ] Diseñar y crear modelo de datos en PostgreSQL
- [ ] Implementar autenticación y perfiles
- [ ] Crear y configurar partidos
- [ ] Implementar invitaciones y lista de jugadores
- [ ] Implementar votación de disponibilidad
- [ ] Implementar cálculo y registro manual de cuotas
- [ ] Implementar resultados, goleadores y estadísticas

## Fase 2 — Mejoras

- Recordatorios automáticos
- Suplentes automáticos
- Balanceo de equipos
- Historial de enfrentamientos
- Perfiles públicos de equipos
- Compartir resultados

## Fase 3 — Crecimiento

- Buscador de rivales
- Publicación de partidos abiertos
- Integración con Mercado Pago
- Gestión de torneos y ligas
- Panel para dueños de cancha
